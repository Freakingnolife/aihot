## Working notice

This is an unapproved working notice for the private AdditiveOS Radar pilot. It is not an approved public privacy policy. Retention periods and public operating arrangements have not been approved.

## Browser storage

Bookmarks, read history, preferences and feedback drafts may be stored in this browser. Clearing browser storage removes those local records. Exported bookmark files stay wherever you save them.

## Feedback and local operation

The feedback form sends the text, optional email, page information and any attached screenshot to the pilot backend. Do not submit secrets, identity documents or unrelated sensitive information. Server logs may contain request information needed to diagnose failures.

The reader runs locally on loopback. Collection occurs only in explicitly run manual batches. Opening a reader page does not start a model call. The pilot has no report cron or automatic Chinese translation job.
